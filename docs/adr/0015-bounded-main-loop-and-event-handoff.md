# 主循环按预算推进服务，按来源交接中断数据

裸机运行时由 `port` 提供时间、中断与同步原语。`app` 按固定顺序推进各服务，服务拥有各自的状态机。运行期间每步工作量有上界，Flash 擦写安排在空闲且未采样时。事件通过专用缓冲、FIFO 或锁存记录交接，以保留各来源所需的顺序、计数和优先级。

电流采样沿用 V2.0 的连续环形 DMA 模式，主循环直接将样本归约为每串的和与点数。每串边界单独记录生产序号，过流归属由首个保护事件锁存。样本和边界容量按最坏消费间隔定值，并显式检测覆盖和丢失。本决定取代 ADR-0008 中的可合并串结束标志和逐串 DMA。

## 考虑过的方案

- **全局业务事件队列**：所有来源共用容量和排队顺序，普通流量会影响关键输入。专用通道让保护、边沿、字节和样本各自定义过载行为。
- **逐串重装 DMA**：必须在下一串的首个采样前完成数据交接与重装，最短串间隔为 1 ms。连续 DMA 将重装移出串间时限。
- **复制整串到第二个环形缓冲**：中断拷贝增加随串长变化的耗时，主循环拷贝仍有原缓冲覆盖时限。本板只需要统计结果与过流尾部样本。
