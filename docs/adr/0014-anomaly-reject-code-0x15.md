# 电流异常态的拒绝码用 0x15，取代协议 V0.2 的 0x13

以 SRS V0.6（I-011）为准：拒绝码取 0x11 运行中、0x12 模式异常（启停源不匹配）、0x13 前置条件不满足、0x15 电流异常态、0x03 参数非法、0x04 不支持、0x20 写入失败。

协议 V0.2 把电流异常态记为 0x13，与"前置条件不满足"共用同一码；本版把电流异常态固定为 0x15，0x13 只表示前置条件不满足。

放弃的方案：

- **沿用 V0.2 的 0x13**：与"前置条件不满足"共用同一码，主机无法区分，且与 SRS V0.6 冲突。

## Consequences

- `ecsp_reason` 的 `ECSP_ANOMALY` 映射 0x15、`ECSP_PRECOND` 映射 0x13，`ecsp_reason_to_ack()` 是唯一映射点。
- 旧实现/旧协议文档若仍按 0x13 判电流异常态，会误读为前置条件不满足，需同步。
