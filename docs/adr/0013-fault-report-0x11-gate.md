# 故障 0x11 上报门槛：上传模式开，或本会话收到过指向本板的合法命令帧

故障位 0→1 时，只有满足下面两个条件之一才立即上报 0x11：上传模式（0x0F）为开；或本会话内已收到过至少一条指向本板的合法命令帧（I-030）。满足时不受事件队列门控限制。

本版 0x11 的唯一来源是未运行时锁存过流置起的 bit1（bit0 因自检不实现恒 0）；运行中过流不属于故障，只发 0x3C（见 ADR-0008）。

放弃的方案：

- **无条件主动上报**：主机关掉上传模式后仍可能被未请求的帧打扰，违背上传模式的语义。
- **仅上传模式门控**：主机刚发过命令、还没显式开上传模式时，故障会被静默吞掉，主机无法及时知道。

## Consequences

- `ecsp` 在会话状态里记住"本会话是否收到过指向本板的合法命令帧"。
- 握手请求到达时清空该位（会话重建）。
